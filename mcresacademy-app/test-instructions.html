📋 Test Instructions

Constable Grand Test - 1
200 Questions • 200 Marks • Duration: 180 Minutes
Negative Marking: -0.25 for each wrong answer
⚠️ ముఖ్య గమనిక: Start Test నొక్కిన తర్వాత Timer Start అవుతుంది. Time అయిపోగానే Test Automatic గా Submit అవుతుంది. మధ్యలో Page Close చేసినా / Refresh చేసినా Timer ఆగదు.

General Instructions

  1. ఒక్కో ప్రశ్నకు 4 Options ఉంటాయి. సరైనది ఒక్కటే.
  2. Answer మార్చుకోవచ్చు - Submit చేసే వరకు ఎన్నిసార్లైనా మార్చుకోవచ్చు.
  3. Skip చేయవచ్చు - తర్వాత Question Palette నుండి మళ్ళీ రావచ్చు.
  4. Negative Marking - తప్పు సమాధానానికి పైన చెప్పిన Marks తగ్గుతాయి. తెలియని ప్రశ్నలకు Guess చేయకండి.
  5. Internet - Test మధ్యలో Internet పోతే, తిరిగి వచ్చాక అదే చోట నుండి Continue అవుతుంది (Backend వచ్చాక).
  6. Malpractice - Tab మార్చడం / Copy చేయడం వంటివి చేస్తే Test Auto Submit అయ్యే అవకాశం ఉంది.

Marking Scheme

  • Correct Answer: +1 Mark
  • Wrong Answer: -0.25 Mark (ఈ Test కి)
  • Not Attempted: 0 Mark

Question Palette - రంగుల అర్థం

1 Answered - సమాధానం ఇచ్చారు
2 Not Answered - చూడలేదు / సమాధానం ఇవ్వలేదు
3 Marked for Review - తర్వాత చూడాలని Mark చేశారు
4 Answered & Marked - సమాధానం ఇచ్చి Review కి Mark చేశారు
